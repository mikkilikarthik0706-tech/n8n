How the
AI Telegram Workflow
Actually Works

A technical breakdown of my first production n8n automation — from incoming Telegram message to AI-generated response.

Telegram Trigger Updates: message
Basic LLM Chain AI Processing Layer
Send a Text Message sendMessage: message
OpenAI Chat Model GPT
Google Gemini Chat Model Gemini

Both models connect to the Basic LLM Chain as configurable fallback options

n8n Workflow Canvas — AI Telegram Bot
01

Trigger

The Telegram Trigger node listens for incoming messages via webhook. When a user sends a message to the Telegram bot, n8n immediately receives the update and passes the message payload downstream.

02

Processing

The Basic LLM Chain receives the raw message and forwards it to the configured language model. This node handles prompt formatting, API calls, and response extraction — abstracted cleanly by n8n.

03

AI Models

Both OpenAI (GPT) and Google Gemini are connected as configurable model options. The workflow supports a fallback pattern — if one model is unavailable, the chain can switch to the other.

04

Output

The Send a Text Message node takes the AI-generated response and sends it back to the originating Telegram chat — completing the automated conversation loop without any manual intervention.

Workflow 02

AI Invoice
Reminder System

A multi-branch automation that handles the full invoice reminder lifecycle — from scheduled data fetch to AI-drafted, urgency-routed Gmail delivery.

n8n Workflow Canvas — AI Invoice Reminder Automation
01

Daily Schedule Trigger

The Daily Review node fires automatically on a set schedule each day, initiating the invoice check pipeline without any manual intervention.

02

Fetch & Read Invoice Data

Fetch Pending Invoices and Get row(s) in sheet nodes pull all outstanding invoice records from Google Sheets, including client details, amounts, and due dates.

03

Compute Days Until Due

The Compute Days Until Due node calculates the number of days remaining (or overdue) for each invoice, which determines the urgency routing path downstream.

04

AI Message Generation

OpenAI (Message a model) drafts a contextually appropriate reminder message using invoice details — different tones for upcoming vs. overdue scenarios.

05

Urgency Routing & Delivery

Conditional nodes route each invoice: Upcoming 1–3 days sends a friendly reminder; Overdue 1–15 days triggers an overdue alert and separately notifies the Accounts Team — all via Gmail. The Last Reminder Date is updated in the sheet after delivery.
